# What is this?

It is a Web UI for file management with a goofy name.

You can manage the following:

- ROMs
- Saves
- Save States
- BIOS
- Box Art
- Wallpapers
- Overlays
- Shaders
- Guides (with in-app preview for PDFs, images, and text/markdown)

Plus tools:

- File Manager (browse device storage)
- APK Installer

---

# How do I use it?

1. Open settings and pick `Nonna's Kitchen`.
2. Scan the QR Code or enter the URL into a browser.
3. Enter the PIN shown on screen.
4. Manage your files.
